主な機能

WASAPI 排他出力

共有ミキサーを介さない排他モード。USB DAC向けにそのままの形式で出力します。

DSD Native / DoPv1.3

DSF/DFFのDSD64/128/256に対応。DoPはWASAPI排他、NativeはASIO DSD対応ドライバ経由。音量はDAC側で調整します。

LRCLIB 歌詞同期

同期歌詞の取得・自動追従・行クリックでシーク。LRCLIB停止時はlyrics.ovhのプレーン歌詞にフォールバックします。

YouTube 検索 / ストリーミング

検索結果からすぐ再生。URLから曲・プレイリスト・アルバム・ミックスを取り込めます。

ライブラリ / キュー

ローカル音源をアルバム単位で分類。右クリックで次に再生・キュー追加、シャッフル再生に対応。

yt-dlp ダウンロード

MP3/M4A/FLACで保存。プレイリスト全体はプレイリスト名のアルバムとしてタグ整理します。

インストール / 更新

配布は USSBAP.msi です。ダブルクリックしてインストールしてください。

  • インストール先：%LOCALAPPDATA%\Programs\USSBAP（ユーザー単位・管理者不要）
  • アプリ内の「設定 → アプリ情報 / アップデート」から更新を確認できます
  • 更新はアプリ内で完結し、インストーラ画面は表示されません
  • 設定・歌詞キャッシュ・ストリーム/サムネイルキャッシュ・yt-dlp/ffmpeg は更新後も保持されます
  • 起動時に1日1回、更新を自動確認します

DSD について

  • DoP：WASAPI排他でPCMフレームにDSDを包んで送出。DAC側のDoP対応が必要です。DSD64=176.4kHz、DSD128=352.8kHz、DSD256=705.6kHz
  • Native：ASIO DSD対応ドライバとUSB DACが必要。未対応の場合はDoPへ自動フォールバックします
  • DSD再生中はソフトウェア音量を無効化します（100%固定）。音量はDAC側で調整してください
  • DST圧縮されたDFFは非対応です
  • DoP非対応のDACにDoPを送るとノイズになるため、必ずDACの対応を確認してください

動作環境・注意

OS

Windows 10 / 11 (64bit)。.NETランタイムのインストールは不要です（自己完結）。

ネットワーク

YouTube / LRCLIB / 更新確認にインターネット接続を使用します。yt-dlp・ffmpegは未検出時に取得できます。

署名

現在は自己署名証明書で署名しています。他のPCではSmartScreen警告が出る場合があります。同梱の証明書を信頼するか、CA発行の証明書で再署名してください。

BASS / BASSASIO / BASSDSD を同梱しています。これらは非商用利用では無料ですが、商用利用にはBASSのライセンスが必要です。詳細はインストール先の licenses フォルダを確認してください。
